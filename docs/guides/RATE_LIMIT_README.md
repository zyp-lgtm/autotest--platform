# 前端速率限制倒计时功能

## 功能说明

为注册和登录页面添加了速率限制倒计时显示功能，当触发速率限制时自动显示剩余等待时间。

## 实现内容

### 1. 更新 API 客户端 (`frontend/src/api/client.ts`)
- 添加 429 状态码检测
- 提取 `retry_after` 参数
- 将速率限制信息附加到错误对象

### 2. 创建错误处理工具 (`frontend/src/utils/errorHandler.ts`)
```typescript
// 工具函数
isRateLimitError(error) // 检查是否为速率限制错误
getErrorMessage(error)  // 获取友好的错误消息
getRetryAfter(error)    // 获取等待时间
```

### 3. 创建倒计时组件 (`frontend/src/components/ui/RateLimitCountdown.tsx`)
- 显示剩余等待秒数（大号字体）
- 进度条可视化
- 自动更新倒计时
- 倒计时结束后提示可重试

### 4. 更新注册页面 (`frontend/src/pages/Register.tsx`)
- 检测速率限制错误
- 显示倒计时组件替代普通错误消息
- 倒计时结束后自动恢复表单

### 5. 更新登录页面 (`frontend/src/pages/Login.tsx`)
- 同注册页面相同的速率限制处理

## UI 效果

### 触发速率限制时
```
┌─────────────────────────────────────────┐
│ ⚠️ 请求过于频繁                         │
│                                         │
│ 为保护系统安全，请等待 [ 15 ] 秒后再试 │
│                                         │
│ ████████████████████░░░░░░░░░░░░░░░░ │
└─────────────────────────────────────────┘
```

### 倒计时结束后
```
┌─────────────────────────────────────────┐
│ ✅ 可以重试了                           │
│ 现在可以重新提交注册请求                │
└─────────────────────────────────────────┘
```

## 使用示例

用户在注册/登录时如果触发速率限制（3次请求/15秒）：
1. 自动显示倒计时组件
2. 倒计时从实际等待秒数开始递减
3. 进度条动态显示剩余时间比例
4. 倒计时结束后自动恢复表单状态

## 后端 API 响应格式

```json
{
  "detail": "Too many requests",
  "retry_after": 15
}
```

## 技术要点

- 使用 `useEffect` 和 `setInterval` 实现倒计时
- 自动清理定时器防止内存泄漏
- 进度条宽度动态计算
- 响应式设计适配移动端
- 无障碍支持（图标 + 文字）
