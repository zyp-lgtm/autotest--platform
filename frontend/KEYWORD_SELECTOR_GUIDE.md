# 关键字选择器使用指南

## 🎯 核心功能概述

关键字选择器和元素选择器是测试自动化平台的两大核心辅助功能：

### 1. **关键字选择器** (KeywordSelector)
用于选择测试操作类型，如点击、输入、断言等

### 2. **元素选择器** (ElementPicker) 🆕
帮助您准确选择网页元素，提供完整的CSS选择器获取指南

## 🎯 如何使用元素选择器 (NEW!)

### 什么是元素选择器？

元素选择器是一个交互式指南，帮助您：
- ✅ 学习如何准确选择网页元素
- ✅ 理解不同类型的CSS选择器
- ✅ 掌握浏览器开发者工具的使用
- ✅ 避免常见的选择器错误

### 何时使用元素选择器？

**需要在以下情况使用元素选择器**：
- 📍 需要点击按钮 → 需要按钮的CSS选择器
- ⌨️ 需要输入文本 → 需要输入框的CSS选择器
- 👁️ 需要验证元素 → 需要元素的CSS选择器
- 🖼️ 需要截图元素 → 需要元素的CSS选择器

### 如何打开元素选择器？

1. **进入步骤创建页面**
   - 任务管理 → 管理场景 → 创建/编辑用例 → 添加步骤

2. **选择一个需要元素选择器的关键字**
   - 例如：CLICK、INPUT、ASSERT_VISIBLE 等

3. **点击"🎯 元素选择器"按钮**
   - 在参数配置区域的右上角

### 元素选择器5步指南

#### 第1步：准备测试页面 🌐
```
在另一个浏览器标签页中打开您要测试的网页
```

#### 第2步：打开开发者工具 🔧
```
Windows: 按 F12
Mac: 按 Cmd+Option+I
或者：右键点击页面 → 选择"检查"
```

#### 第3步：激活元素选择器 🎯
```
点击开发者工具左上角的选择器图标
快捷键: Ctrl+Shift+C (Windows) / Cmd+Shift+C (Mac)
```

#### 第4步：选择目标元素 👆
```
将鼠标悬停在页面上，目标元素会高亮显示
点击您要测试的元素
```

#### 第5步：复制CSS选择器 📋
```
在开发者工具中，右键点击高亮的HTML元素
选择: Copy → Copy selector
```

### 常用CSS选择器类型

#### 1. ID选择器（推荐 ⭐⭐⭐⭐⭐）
```css
#username-input
#login-button
```
**优点**: 最快最稳定，ID通常是唯一的

#### 2. 类选择器（推荐 ⭐⭐⭐⭐）
```css
.login-button
.input-field
```
**优点**: 可读性好，但可能不唯一

#### 3. 属性选择器（推荐 ⭐⭐⭐⭐⭐）
```css
[data-testid="submit"]
[data-role="login-form"]
[name="username"]
```
**优点**: 最稳定，专为测试设计

#### 4. 组合选择器（推荐 ⭐⭐⭐）
```css
form input[type="text"]
.container .login-button
```
**优点**: 精确定位，但较复杂

### 元素选择器测试功能

在元素选择器界面中，您可以直接测试您的选择器：

1. **粘贴选择器**
   ```
   将从开发者工具复制的CSS选择器粘贴到输入框
   ```

2. **确认选择**
   ```
   点击"确认选择"按钮，选择器会自动填入参数配置中
   ```

3. **清空重试**
   ```
   如果选择器不正确，点击"清空"按钮重新输入
   ```

### 最佳实践建议

#### ✅ 推荐做法

1. **优先使用 data-testid 属性**
   ```html
   <!-- 在开发时添加测试专用属性 -->
   <button data-testid="submit-button">提交</button>
   ```
   ```css
   /* 测试时使用 */
   [data-testid="submit-button"]
   ```

2. **使用语义化的选择器**
   ```css
   /* ✅ 好 */
   #login-button
   [data-role="primary-button"]

   /* ❌ 差 */
   div > div:nth-child(2) > button
   ```

3. **保持选择器简单**
   ```css
   /* ✅ 好 - 简单直接 */
   #username

   /* ❌ 差 - 过于复杂 */
   body div.container form fieldset div input[type="text"]:nth-child(1)
   ```

#### ❌ 避免的做法

1. **不要使用索引选择器**
   ```css
   /* ❌ 容易失效 */
   button:nth-child(3)
   :nth-child(2)
   ```

2. **不要依赖文本内容**
   ```css
   /* ❌ 文本变化会失效 */
   button:contains("提交")
   ```

3. **不要使用过长的选择器**
   ```css
   /* ❌ 难以维护 */
   html body div.main div.content div.wrapper form div.input-group input
   ```

## 📋 关键字选择器基础

### 如何访问关键字选择器？

### 1. 访问关键字选择器

1. 从任务管理页面点击"管理场景"按钮
2. 在场景页面中创建或编辑测试用例
3. 在步骤编辑表单中会看到关键字选择器组件

### 2. 选择器界面说明

```
┌─────────────────────────────────────────────┐
│ 当前选择: CLICK [点击元素]        [更换]     │
├─────────────────────────────────────────────┤
│ 🔍 [搜索关键字...]    [▼ 全部类别]         │
├─────────────────────────────────────────────┤
│ 📁 浏览器操作                                │
│   • OPEN_BROWSER    [示例]                 │
│   • CLOSE_BROWSER   [示例]                 │
│   • SWITCH_TAB      [示例]                 │
│                                              │
│ 📁 元素操作                                  │
│   • CLICK           [示例]                 │
│   • INPUT           [示例]                 │
│   • DOUBLE_CLICK    [示例]                 │
│                                              │
│ 📁 断言操作                                  │
│   • ASSERT_VISIBLE   [示例]                │
│   • ASSERT_TEXT      [示例]                │
└─────────────────────────────────────────────┘
```

### 3. 功能特点

#### 搜索功能
- 在搜索框中输入关键字名称或描述
- 支持模糊搜索，实时过滤结果

#### 分类过滤
- 点击类别下拉菜单选择特定类别
- 可选类别：
  - 全部类别
  - 浏览器操作
  - 元素操作
  - 断言操作
  - 等等...

#### 查看示例
- 点击"示例"按钮查看该关键字的参数示例
- 示例显示为 JSON 格式，帮助您了解如何配置参数

### 4. 选择关键字流程

1. **搜索或浏览**
   - 使用搜索框查找特定关键字
   - 或使用类别下拉菜单浏览

2. **查看详情**
   - 点击"示例"按钮查看参数示例
   - 确认该关键字符合测试需求

3. **确认选择**
   - 点击关键字名称确认选择
   - 选中的关键字会显示在顶部

4. **更换选择**
   - 如果选错了，点击"更换"按钮重新选择

### 5. 常用关键字说明

#### 浏览器控制
- **OPEN_BROWSER**: 打开浏览器
- **CLOSE_BROWSER**: 关闭浏览器
- **SWITCH_TAB**: 切换标签页
- **GO_BACK**: 后退
- **REFRESH**: 刷新页面

#### 元素操作
- **CLICK**: 点击元素
- **INPUT**: 输入文本
- **DOUBLE_CLICK**: 双击元素

#### 断言验证
- **ASSERT_VISIBLE**: 断言元素可见
- **ASSERT_TEXT**: 断言文本内容

### 6. 参数配置示例

#### CLICK 关键字示例
```json
{
  "selector": "#login-button",
  "timeout": 5000
}
```

#### INPUT 关键字示例
```json
{
  "selector": "#username-input",
  "value": "testuser",
  "timeout": 3000
}
```

#### ASSERT_TEXT 关键字示例
```json
{
  "selector": ".welcome-message",
  "expected": "欢迎回来",
  "timeout": 5000
}
```

### 7. 最佳实践

1. **选择合适的关键字**
   - 根据测试目的选择对应的关键字
   - 优先使用断言关键字验证结果

2. **查看示例配置**
   - 不确定参数格式时点击"示例"查看
   - 参考示例配置您自己的参数

3. **合理设置超时**
   - 根据网络环境调整 timeout 参数
   - 避免设置过短导致超时失败

4. **使用类别过滤**
   - 熟悉关键字分类后，使用类别过滤提高效率
   - 记住常用关键字所在的类别

### 8. 疑难解答

**Q: 找不到需要的关键字？**
A: 尝试使用搜索功能，或者选择"全部类别"查看所有关键字。

**Q: 不确定参数如何配置？**
A: 点击"示例"按钮查看该关键字的参数示例。

**Q: 选择错误如何更换？**
A: 点击右上角的"更换"按钮即可重新选择。

**Q: 关键字太多难以查找？**
A: 使用搜索功能或类别过滤来缩小范围。

## 9. 任务管理中的关键字统计

在任务管理页面，每个任务卡片会显示：
- **场景数**: 包含的测试场景数量
- **关键字数**: 使用的不同关键字数量
- **关键字标签**: 显示前5个使用的关键字

这帮助您快速了解任务的测试覆盖范围和使用的测试技术。
