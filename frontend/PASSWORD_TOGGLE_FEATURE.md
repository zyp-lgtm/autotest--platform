# 密码显示/隐藏功能

## 功能说明

为注册和登录页面添加了密码显示/隐藏切换功能，提升用户体验。

## 实现内容

### 1. 注册页面 (`Register.tsx`)

#### 新增功能
- ✅ 密码输入框显示/隐藏按钮（眼睛图标）
- ✅ 确认密码输入框显示/隐藏按钮
- ✅ 独立控制两个密码框的显示状态
- ✅ 使用 Lucide React 图标库的 `Eye` 和 `EyeOff` 图标

## 技术实现

### 状态管理
```typescript
// 注册页面：两个独立的显示状态
const [showPassword, setShowPassword] = useState(false)
const [showConfirmPassword, setShowConfirmPassword] = useState(false)

// 登录页面：单个显示状态
const [showPassword, setShowPassword] = useState(false)
```

### 切换逻辑
```typescript
// 切换密码显示
onClick={() => setShowPassword(!showPassword)}

// 根据状态切换输入框类型
type={showPassword ? 'text' : 'password'}
```

### 图标切换
```typescript
{showPassword ? (
  <EyeOff className="w-5 h-5" />  // 隐藏密码图标
) : (
  <Eye className="w-5 h-5" />        // 显示密码图标
)}
```

### 样式定位
```css
/* 相对定位容器 */
.relative {
  position: relative;
}

/* 图标按钮 */
button {
  position: absolute;
  right: 0.75rem;  /* right-3 */
  top: 2.1rem;   /* 输入框下方 */
  color: rgb(107 114 128);  /* text-gray-500 */
  cursor: pointer;
}

button:hover {
  color: rgb(55 65 81);  /* text-gray-700 */
}
```

## 功能特性

| 特性 | 说明 |
|------|------|
| **独立控制** | 注册页面的两个密码框独立控制 |
| **一键切换** | 点击图标立即切换显示/隐藏 |
| **视觉反馈** | 鼠标悬停时图标颜色加深 |
| **无障碍支持** | 按钮包含 `aria-label` 说明 |
| **样式一致** | 与整体设计风格保持一致 |
| **键盘友好** | 使用 `tabIndex={-1}` 避免焦点捕获 |

## 图标说明

- **Eye（睁眼）**: 当前显示密码（明文）
- **EyeOff（闭眼）**: 当前隐藏密码（掩码）

## 安全提示

虽然用户可以查看密码，但：
- ✅ 输入框仍使用 `type="password"` 作为默认
- ✅ 密码不会在 URL 或日志中明文显示
- ✅ 服务器端仍然接收加密密码
- ✅ 便于用户确认输入正确，避免错误
